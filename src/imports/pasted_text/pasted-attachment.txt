# CONNX — Build Pass 3

Three more recruiter surfaces, fully built: **Roles & Candidates**, **Consent Center**, and **Templates Library**. Plus the **role detail** page with the full filterable, bulk-actionable candidate table.

## What's in Pass 3

**8 files total** — 2 new UI primitives, 1 mock data file, 4 pages, 1 router update.

### New files

That's it. Click "Roles & candidates" or "Consent center" or "Templates" in the sidebar and you're in.

## What you'll see

### Roles & Candidates (`/roles`)
- 6 open roles in a 2-column card grid, each with: title, team, location, days open, JD summary, 4-stage funnel strip (Shortlisted → Consented → Screened → Advanced) with conversion percentages, hiring manager avatar, target/actual badge
- Health badges per role: On track / At risk / Stalled
- Search by title/team, filter by team, sort by newest / longest open / most advanced / health
- Click any role → role detail

### Role detail (`/roles/:id`)
- Header with role meta + `Start dialer for this role` and `Bulk message` CTAs
- 5-stat strip: Shortlisted / Consented (with %) / Screened (with %) / Advanced / Rejected
- Stage tabs: All / Shortlisted / Consented / Screened / Advanced / Rejected (with counts)
- Candidate table with avatar, current role+company, consent badge, stage, source, last activity
- Search by name/company/skill, filter by consent status and source, export
- **Bulk action bar** (appears when rows selected): Add to queue, SMS, Email — slides in from below
- Row hover reveals quick-call button + 3-dot menu (View profile, Add to queue, SMS, Email, Schedule callback, Resend consent if expired, Reject)
- Responsive: hides progressively less-essential columns on smaller screens

### Consent Center (`/consent`)
- 5-stat strip: Pending / Accepted / Declined / Expired / Acceptance rate
- Two tabs: **Consent queue** + **Audit trail**
- **Queue:** filter by status + role, contextual bulk-action callouts (e.g. "5 pending consents · oldest 2 days ago · Send 48h reminder to all"), per-candidate quick actions revealed on hover (Resend SMS, Resend email, Re-consent for expired, Add to queue for accepted)
- **Audit trail:** tamper-evident log of every consent action (sent, resent, accepted, declined, expired, callback requested, opt-out, language change, reminder sent), with channel badge (SMS/EMAIL/SYSTEM), timestamp, candidate, role, and detail with IP for accepted ones. Compliance-grade.

### Templates Library (`/templates`)
- Channel tabs: All / SMS / Email / Voicemail / Screening question sets (with counts)
- Two-column layout: list of templates left, **live preview** right
- Filter by stage (consent / follow-up / screening / offer / rejection / general), search by name/body/description
- Each template: name, description, favourite star, lock icon if admin-managed, stage badge, "used in N roles" badge, last used hint
- **Live preview:**
  - **SMS** → renders as a phone message bubble with character count and segment count
  - **Email** → renders as an email card with from/to/subject/body
  - **Voicemail** → renders as a quoted script with estimated duration
  - **Screening** → renders as numbered question cards
- **Render against** dropdown lets you pick any candidate to see merge fields resolved in real time
- Unresolved merge fields highlighted in amber (so recruiters spot template bugs before sending)
- Per-template actions: Favourite, Duplicate, Edit, Delete (Edit/Delete disabled when admin-locked)

## Design moves I made

1. **Bulk actions live in a slide-up bar at the top, not a footer.** Cosmic-indigo dark band so it pops above the candidate table without competing with row hovers. Three-action limit (queue, SMS, email) keeps it scannable.

2. **The audit trail is presented as a story, not a database dump.** Each entry has an icon, an action verb in semantic color, the candidate, the role, and a meaningful detail line ("Accepted via SMS reply 'YES'. IP: 73.142.18.91"). Compliance teams will love it; recruiters can actually skim it.

3. **Templates preview against real candidates, not a blank `{{firstName}}`.** This is the move that makes the Templates page useful instead of bureaucratic. Picking "Aisha Okafor" shows the recruiter exactly what the candidate will receive.

4. **Stage filters and consent filters are on different axes.** Stage = where they are in the pipeline (Shortlisted → Advanced). Consent = where they are with comms (Pending / Accepted / Declined). Recruiters need both because "consented but not screened" and "screened but rejected" are completely different action plans.

5. **Per-role pipeline strip mirrors the dashboard funnels.** Same 4-step structure (Shortlisted → Consented → Screened → Advanced), so recruiters never have to relearn the visual grammar moving between surfaces.

6. **Mobile**: 2-column role grid → 1-column. Candidate table progressively hides Source (xl), Last activity (lg), Current role (lg), Stage (md). Templates layout stacks list above preview.

## What's next (Pass 4)

The hero flow: **Auto Dialer**. Three sub-screens: Queue Builder (pick role, pick candidates, set priority), Customise Call View (the BRD-mandated pre-session pill-based layout config), and the **Active Call** screen — the 50/30/20 layout with the panel pill bar, in-call controls, voicemail drop, disposition flow, and the floating Notes shortcut. This is the screen this product gets built around.

import { useState, useMemo } from "react";
import { useNavigate } from "react-router-dom";
import {
  Plus, Search, Briefcase, MapPin, Calendar, Users, ChevronRight,
  AlertTriangle, CheckCircle2, Clock, ArrowUpDown, SlidersHorizontal,
} from "lucide-react";
import { Card, CardContent } from "@/components/ui/card";
import { Button } from "@/components/ui/button";
import { Input } from "@/components/ui/input";
import { Badge } from "@/components/ui/badge";
import { NameAvatar } from "@/components/ui/avatar";
import {
  Select, SelectTrigger, SelectValue, SelectContent, SelectItem,
} from "@/components/ui/select";
import { ROLES } from "@/data/mock";
import { ROLE_PIPELINES } from "@/data/dashboard-mock";
import { cn } from "@/lib/utils";

const HEALTH = {
  "on-track": { label: "On track", icon: CheckCircle2, color: "text-success-ink", bg: "bg-success-soft" },
  "at-risk": { label: "At risk", icon: Clock, color: "text-warning-ink", bg: "bg-warning-soft" },
  "stalled": { label: "Stalled", icon: AlertTriangle, color: "text-danger-ink", bg: "bg-danger-soft" },
} as const;

type SortKey = "newest" | "stage" | "stalled" | "open";
type FilterTeam = "all" | "Platform" | "Product" | "Data" | "Sales";

export default function RolesPage() {
  const navigate = useNavigate();
  const [query, setQuery] = useState("");
  const [team, setTeam] = useState<FilterTeam>("all");
  const [sort, setSort] = useState<SortKey>("newest");

  const enriched = useMemo(() => {
    return ROLES.map((r) => {
      const p = ROLE_PIPELINES.find((pp) => pp.roleId === r.id)!;
      return { ...r, ...p };
    });
  }, []);

  const filtered = useMemo(() => {
    let out = enriched;
    if (team !== "all") out = out.filter((r) => r.team === team);
    if (query) {
      const q = query.toLowerCase();
      out = out.filter((r) => r.title.toLowerCase().includes(q) || r.team.toLowerCase().includes(q));
    }
    if (sort === "newest") out = [...out].sort((a, b) => +new Date(b.openedAt) - +new Date(a.openedAt));
    if (sort === "open") out = [...out].sort((a, b) => b.daysOpen - a.daysOpen);
    if (sort === "stage") out = [...out].sort((a, b) => b.advanced - a.advanced);
    if (sort === "stalled") out = [...out].sort((a, b) => {
      const order = { stalled: 0, "at-risk": 1, "on-track": 2 };
      return order[a.health] - order[b.health];
    });
    return out;
  }, [enriched, team, query, sort]);

  const totals = useMemo(() => ({
    open: ROLES.length,
    candidates: ROLES.reduce((acc, r) => acc + r.shortlisted, 0),
    advanced: ROLES.reduce((acc, r) => acc + r.advanced, 0),
    stalled: enriched.filter((r) => r.health === "stalled").length,
  }), [enriched]);

  return (
    <div className="p-4 lg:p-6 xl:p-8 max-w-[1280px] mx-auto">
      {/* Header */}
      <div className="flex flex-col md:flex-row md:items-center md:justify-between gap-3 mb-5">
        <div>
          <h1 className="mb-1">Roles &amp; candidates</h1>
          <p className="text-muted-fg t-body-large">
            {totals.open} open roles · {totals.candidates} candidates in flight · {totals.advanced} advanced
          </p>
        </div>
        <div className="flex items-center gap-2">
          <Button variant="outline" size="sm">
            <SlidersHorizontal className="h-3.5 w-3.5" />
            Filters
          </Button>
          <Button size="sm">
            <Plus className="h-3.5 w-3.5" />
            New role
          </Button>
        </div>
      </div>

      {/* Toolbar */}

function resolveMergeFields(text: string, candidate: any, role: any): string {
  const recruiterFirst = CURRENT_RECRUITER.name.split(" ")[0];
  const candidateFirst = candidate.name.split(" ")[0];
  const map: Record<string, string> = {
    firstName: candidateFirst,
    candidateFullName: candidate.name,
    phone: candidate.phone,
    email: candidate.email,
    recruiterFirstName: recruiterFirst,
    recruiterFullName: CURRENT_RECRUITER.name,
    recruiterTitle: "Senior Talent Partner",
    recruiterCallback: "+1 (628) 555-0184",
    orgName: ORG.name,
    roleTitle: role.title,
    teamName: role.team,
    location: role.location,
    jdSummary: role.jdSummary,
    consentLink: "northwind.connx.app/c/k7Yh2",
    callbackTime: "Tuesday at 2:00 PM",
  };
  return text.replace(/\{\{(\w+)\}\}/g, (_, key) => map[key] ?? `{{${key}}}`);
}

// Highlight unresolved merge fields visually
function renderWithMergeHighlight(text: string, candidate: any, role: any) {

  const parts = resolved.split(/(\{\{\w+\}\})/g);
  return parts.map((p, i) =>
    /^\{\{\w+\}\}$/.test(p)
      ? <span key={i} className="bg-warning-soft text-warning-ink px-1 rounded-sm">{p}</span>
      : <span key={i}>{p}</span>
  );
}

                  <Badge variant="neutral" size="sm" className="gap-1">

              </Button>
              <Button variant="ghost" size="icon-sm" aria-label="Duplicate">
                <Copy className="h-3.5 w-3.5" />
              </Button>
              <Button variant="ghost" size="icon-sm" disabled={t.isLocked} aria-label="Edit">
                <Edit3 className="h-3.5 w-3.5" />
              </Button>
              <Button variant="ghost" size="icon-sm" disabled={t.isLocked} aria-label="Delete" className="text-danger-ink">
                <Trash2 className="h-3.5 w-3.5" />

          <div className="flex items-center justify-between gap-3">
            <div className="flex items-center gap-2">
              <Eye className="h-4 w-4 text-stellar" />
              <CardTitle>Live preview</CardTitle>
            </div>

                  ))}
                </SelectContent>
              </Select>
            </div>
          </div>
        </CardHeader>
        <CardContent>
          {t.channel === "email" && t.subject && (
            <div className="mb-3 pb-3 border-b border-border">
              <div className="t-label-small text-muted-fg mb-1">Subject</div>
              <div className="t-title-medium text-cosmic">
                {renderWithMergeHighlight(t.subject, candidate, role)}
              </div>
            </div>
          )}

          {t.channel === "sms" ? <SmsPreview body={t.body} candidate={candidate} role={role} />
            : t.channel === "voicemail" ? <VoicemailPreview body={t.body} candidate={candidate} role={role} />
            : t.channel === "screening" ? <ScreeningPreview body={t.body} />
            : <EmailPreview body={t.body} candidate={candidate} role={role} />}

          {/* Merge field legend */}
          <div className="mt-4 pt-3 border-t border-border flex items-center justify-between gap-2">
            <div className="flex items-center gap-2 t-body-small text-muted-fg">
              <span className="bg-warning-soft text-warning-ink px-1.5 py-0.5 rounded-sm t-label-small">{"{{merge}}"}</span>
              <span>Unresolved merge fields highlighted</span>
            </div>
            <Button variant="link" size="sm">View all merge fields <ChevronRight className="h-3 w-3" /></Button>
          </div>
        </CardContent>
      </Card>
    </div>
  );
}

function SmsPreview({ body, candidate, role }: { body: string; candidate: any; role: any }) {
  return (

      </div>
      <div className="t-label-small text-muted-fg mt-2 text-right">{body.length} chars</div>
    </div>
  );
}

function EmailPreview({ body, candidate, role }: { body: string; candidate: any; role: any }) {

function VoicemailPreview({ body, candidate, role }: { body: string; candidate: any; role: any }) {
  return (
    <div className="bg-mist rounded-lg p-4">
      <div className="flex items-center gap-2 mb-3">
        <div className="h-8 w-8 rounded-pill bg-quantum/10 flex items-center justify-center">
          <Voicemail className="h-4 w-4 text-quantum" />
        </div>
        <div className="flex-1">
          <div className="t-label-large text-dark">Voicemail script</div>
          <div className="t-body-small text-muted-fg">~{Math.ceil(body.length / 800 * 30)} seconds estimated</div>
        </div>
      </div>
      <div className="bg-white rounded-md p-3 t-body-medium text-dark whitespace-pre-wrap break-words italic border-l-2 border-quantum">
        "{renderWithMergeHighlight(body, candidate, role)}"
      </div>
    </div>
  );
}

function ScreeningPreview({ body }: { body: string }) {
  // Parse numbered questions
  const lines = body.split("\n").filter((l) => l.trim());
  return (
    <div className="space-y-2">
      {lines.map((line, i) => {
        const m = line.match(/^(\d+)\.\s*(.*)$/);
        if (m) {
          return (
            <div key={i} className="flex items-start gap-3 p-3 bg-mist rounded-md">
              <div className="h-6 w-6 rounded-pill bg-stellar text-white flex items-center justify-center t-label-small shrink-0 tabular-nums">
                {m[1]}
              </div>
              <p className="flex-1 t-body-medium text-dark pt-0.5">{m[2]}</p>
            </div>
          );
        }
        return <p key={i} className="t-body-small text-muted-fg">{line}</p>;
      })}
    </div>
  );
}
